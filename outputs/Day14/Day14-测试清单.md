# Day 14 · 轻量用户测试清单（给真人用）

> 项目：栀书心驿 ｜ 日期：2026-09-29
> 用法：**先别解释这个页面怎么用**，把链接交给对方，让他自己照下面 7 条做。
> 你（观察者）只做两件事：**闭嘴** + **记原话**。他问"下一步点哪"时，回答"你想点哪就点哪"。
> 全程 5–8 分钟，不要超过 10 分钟。

## 开场要说的一句话

> 这是一个读书小站，我想看看第一次用的人能不能自己走通。你随便用，卡住了就说出来——**卡住不是你的问题，是这个页面没做好**。

## 任务清单（只读任务，不读操作提示）

| # | 交给对方的任务原话 | 我要观察什么 | 完成 | 卡在哪一步（写具体动作） |
|---|-------------------|--------------|------|--------------------------|
| 1 | 打开这个页面，先看看：**你觉得它是做什么的？** | 能不能在 10 秒内说对（读书 / 写心得） | ☐完成 ☐卡住 | |
| 2 | 把你最近在读的一本书加进来。 | 找不找得到入口；加完之后知不知道成功没成功 | ☐完成 ☐卡住 | |
| 3 | 为这本书写一段你此刻的想法，存下来。 | 有没有发现"必须写点什么"；存完有没有反馈 | ☐完成 ☐卡住 | |
| 4 | 存好之后，去找到**你刚才写的那一段**，读一遍。 | 能不能自己找到"心迹 / 书架"，路径绕不绕 | ☐完成 ☐卡住 | |
| 5 | 找到**这本书自己的页面**，看看上面有什么。 | 能不能从卡片点进去；知不知道自己在哪一层 | ☐完成 ☐卡住 | |
| 6 | 用浏览器的"返回"退回上一页。 | 后退之后是回到他以为的地方，还是跳走了/没反应 | ☐完成 ☐卡住 | |
| 7 | 把它换到**手机屏幕**那样窄，再看一遍。哪里挤、哪里看不清、哪里点不准？ | 具体说得出一处以上才算有效 | ☐完成 ☐卡住 | |

## 结束语（必问三句）

1. 刚才哪一步你最犹豫？
2. 有哪个词或按钮的名字，你当时没看懂？
3. 如果要你明天还来，第一步你会点哪里？

## 记录规矩

- 记**他的原话**，不要记我的理解。
- 他每一次"咦？""这啥？""点哪来着"都是一个卡点，哪怕最后他自己找到了。
- **不在测试过程中改页面**，也不提示操作——先看清楚他卡在哪，再来谈修。

## 今天明确不做

- 按反馈大改版（只挑一处最小的修）。
- 一口气把所有卡点都改掉。
