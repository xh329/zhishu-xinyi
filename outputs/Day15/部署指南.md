# 栀书心驿 · Day 15 CloudBase 部署指南

> 本指南覆盖三件事：① 部署 `/api/health` 云函数；② 把前端静态页上传到 CloudBase 静态托管；③ 浏览器验证 + 三张必交截图的获取方法。
> **重要前提**：部署动作需要**你自己的 CloudBase 账号凭据**，AI（沙箱）无法替你登录。以下步骤在你本机终端执行即可；若某一步报错，把它记下来，Day 20 前补齐即可（Day 15 卡住降级目标：至少保证 `/api/health` 公网可访问）。

## 〇、关于"React 项目"的说明
课程模板写的是"第 2 周的 React 项目"，但栀书心驿实际是**纯静态前端（HTML/CSS/JS，hash 路由）**，没有 React、没有构建步骤。
→ 前端部署与 React 完全一致：**无需 `npm run build`，直接把根目录的静态文件上传到 CloudBase 静态托管**，入口是 `index.html`。下面按这个真实情况写。

## 一、注册并开通 CloudBase（附录 M，约 10–15 分钟）
1. 打开 https://console.cloud.tencent.com/tcb （腾讯云 CloudBase 控制台）。
2. 用微信/QQ/邮箱登录，按提示**实名**（首次需实名才能建环境）。
3. 新建一个**环境**（环境名称随意，如 `zhishu-prod`），套餐选**免费版（按量/基础版）**即可，记下自动生成的 **环境 ID**（形如 `zhishu-xinyi-1gabcde`）。
4. 进入环境后，左侧能看到「云函数」「静态托管」「数据库」入口；今天的额度、到期日期在环境概览页可见（截图用，见第五节）。

## 二、部署 `/api/health` 云函数
> 云函数代码已就绪：`cloudfunctions/health/index.js`（仅 GET，返回 `{ "ok": true, "service": "zhishu-xinyi" }`，不连库）。

1. 安装 CloudBase CLI（一次即可）：
   ```bash
   npm install -g @cloudbase/cli
   ```
2. 登录（会弹出浏览器授权）：
   ```bash
   tcb login
   ```
3. 进入云函数目录并部署（把 `<环境ID>` 换成你自己的）：
   ```bash
   cd cloudfunctions/health
   tcb fn deploy health --e <环境ID>
   ```
4. 开启 **HTTP 触发**（让公网能访问）：
   - 控制台 → 云函数 → 选中 `health` → 「触发管理」→ 新建 **HTTP 触发**；
   - 触发路径填 `/api/health`，保存后会得到一个公网地址，形如：
     `https://<环境ID>.api.tcloudbase.com/api/health`
   - 把这个地址记下来，下面验证用。

### 浏览器验证 /api/health
- 在电脑和**手机**浏览器都打开上面的公网地址；
- 页面应直接显示 JSON：`{ "ok": true, "service": "zhishu-xinyi" }`；
- 地址栏里能看到完整的 `https://...api.tcloudbase.com/api/health`（截图要带地址栏）。
- 用手机打开同伴能访问，即达成"公网可访问返回 JSON"。

## 三、前端静态托管部署（mock / 静态版）
> 当前前端是纯静态文件，直接整站上传即可。

1. 回到项目根目录（含 `index.html` 的那一层）：
   ```bash
   cd "D:\vibe coding\课程任务"
   ```
2. 开通静态托管（首次）：控制台 → 静态托管 → 开通，得到一个**默认域名**，形如：
   `https://<环境ID>-<随机>.tcloudbaseapp.com`
3. 上传整站（CLI 一条命令，把 `<环境ID>` 换成你自己的）：
   ```bash
   tcb hosting deploy . / --e <环境ID>
   ```
   （这会把 `index.html`、`css/`、`js/`、`assets/`、`book.html`、`note.html`、`notes.html` 全部上传；`index.html` 为入口。）
4. 若用控制台上传：静态托管 → 文件管理 → 上传文件夹，选项目根目录即可。

### 浏览器验证前端公网页
- 打开静态托管默认域名（手机也开一次）：应看到「栀书心驿」诗意首页；
- 点「书架 / 心迹」能切换视图（hash 路由本地即可，无需后端）；
- 地址栏可见公网域名即达标（截图要带地址栏）。

> 跨域（CORS）今天**不处理**：前端现在仍读本地 `localStorage`，接口还没接，因此没有跨域问题。Day 16 起接 `/api/*` 时再配。

## 六、余力加练：云函数代码逐段讲解
`cloudfunctions/health/index.js` 各部分作用：
1. **文件头注释** —— 说明这是 Day 15 唯一目标：只管 `/api/health`，不连库、不写业务逻辑，返回固定 JSON。
2. **`'use strict'`** —— 开启严格模式，避免意外创建全局变量，代码更稳。
3. **`exports.main = async (event, context) => {…}`** —— CloudBase 云函数的入口。`event` 是请求信息（含 `httpMethod` 等），`context` 是运行环境信息；用 `async` 是为了将来能 `await` 数据库等操作。
4. **读取请求方法 `event.httpMethod`** —— HTTP 触发会把请求方法注入 `event`；默认按 `GET` 处理。
5. **方法校验分支（非 GET → 405）** —— 只接受 GET，其他方法礼貌回 405 + `method_not_allowed`，符合契约第 0 项。
6. **健康检查返回（200）** —— 返回标准 HTTP 响应对象 `{ statusCode, headers, body }`，`body` 是 JSON 字符串 `{ ok: true, service: 'zhishu-xinyi' }`，证明服务在线、路由可达。
