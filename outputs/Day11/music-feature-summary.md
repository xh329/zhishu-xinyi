# Day 11 追加｜诗意背景乐声（Web Audio 合成）

## 1. 需求

「在原来设计的基础上加一个舒缓的、有诗意的背景音乐，让用户一点开网站，通过诗意的背景和舒缓的音乐感到内心平静（气质参考《寻一个你》前奏）。」

## 2. 两个必须说清楚的前提

| 前提 | 说明 | 应对 |
| --- | --- | --- |
| 《寻一个你》的录音不能直接用 | 受版权保护；且本项目是纯静态站、无后端托管音频资源 | 不下载、不引用任何外部音频，改用 **Web Audio API 现场合成**一段舒缓的五声音阶钢琴式循环（慢速、多留白、长余音、轻回声），气质向该前奏的「安静地靠近」靠拢 |
| 浏览器禁止页面一打开就出声 | 自动播放策略（所有网站的硬限制，非本项目的选择） | 乐声**进站待命**，用户第一次轻点/按键页面任意处即**4 秒淡入**；右上角常驻开关键随时静音，偏好记入 `localStorage`，关过的人下次进站不再自动响起 |

## 3. 音乐设计（`js/music.js`）

- **调式**：C 宫五声音阶（C D E G A），跨三个八度；无半音、无紧张感。
- **节奏**：一「步」1.35 秒（约 44 BPM），每句八步、句内一半是休止——**留白也是曲子的一部分**。
- **结构**：6 句循环（约 65 秒），第 3 句上行到 C5，第 5–6 句落回低音区收束，循环衔接处有 0.5 秒交叠，听感不断。
- **音色**：三角波 + 正弦波轻微失谐（detune 4）叠出「暖」，每音 4.5 秒指数衰减当余音，句首力度稍亮。
- **空间感**：0.48 秒延迟 + 0.34 反馈 + 0.22 湿声，做出「空房间」的纵深，不做重混响。
- **动态**：启动 4 秒线性淡入、停止 1.2 秒淡出——不戛然而止。

## 4. 交互与状态

| 状态 | 按钮外观 | 行为 |
| --- | --- | --- |
| 待命（首次进站） | ♪ + 缓慢呼吸光环 + 旁侧小字「轻触页面任意处，乐声轻轻响起」（9 秒后淡出） | 等第一次轻点/按键 |
| 开 | ♪ 转深叶绿、微微上浮 | 乐声淡入并循环；点击即关 |
| 关 | ♪ 上有一道细斜线（休止的意象），透明度降低 | 静音并记入 `localStorage`；下次进站直接显示「关」，不显示引导语、不自动响起 |

- 全站四页均生效：`index.html`、`book.html`、`note.html`、`notes.html`（各引入一行 `<script src="js/music.js">`）。
- 无障碍：开关键为原生 `<button>`，带 `aria-label`／`aria-pressed` 与 `:focus-visible` 焦点环，键盘可开可关；`prefers-reduced-motion` 下呼吸光环动画关闭。
- 边界处理：若「第一次轻点」正好落在开关键上，不按「启动乐声」处理（否则 pointerdown 开、click 又关，第一次点开关反而静音）。

## 5. 测试（真实浏览器，agent-browser）

| # | 测试 | 结果 |
| --- | --- | --- |
| 1 | 首次进站 | 按钮「待命」+ 呼吸光环 + 引导语；无自动出声（符合浏览器策略） |
| 2 | 轻点页面任意处 | 按钮转「开」，乐声开始（`AudioContext` 正常创建、循环已排程） |
| 3 | 点开关键 | 变「关」+ `zhishu_music=off`；再点即恢复「开」 |
| 4 | 关闭后跳到 `note.html` | 直接显示「关」、不显示引导语；轻点页面**不会**自动响起 |
| 5 | 报错检查 | `agent-browser errors` / `console` 均为空 |

> 修复过程记录：初版 `firstGesture()` 引用了未声明的 `e` → 抛 `ReferenceError` 导致整段监听器失效（轻点页面无反应的根因），已补参数声明；另修复「关闭过乐声的用户进站仍显示待命 + 引导语」的误导状态。
